## Comandos usados
| Comando | Para qué sirve |
|---------|----------------|
| `pwd` | muestra la ruta en la que te encuentras, util para saber dentro de que carpeta vas a crear archivos |
| `cd` | "change directory" sirve para moverte a otra carpeta dentro del directorio actual. Directorio = Carpeta |
| `mkdir` | "make directory" sirve para crear una carpeta dentro del directorio actual |
| `ls -a` | Lista todos los directorios y archivos dentro del directorio en el que te encuentras |
| `git init` | crea un nuevo repositorio vacio o convierte un proyecto existente en un repositorio controlado por versiones |

## Problemas y soluciones
Cree un archivo .gitignore dentro de una carpeta que no correspondia y descubri el comando para visualizar los archivos ocultos CMD + SHIFT + .(punto) para poder verlo y eliminarlo desde la GUI.
